# App Store アップデート説明文（Version 1.2.1）

## 🇯🇵 日本語版

### 今回のアップデート

**バグ修正と安定性の向上**

このアップデートでは、以下の問題を修正しました：

- **タイマー表示の改善**: セッション完了後の再スタート時に、設定した時間が正しく表示されるようになりました
- **アニメーションの修正**: セッション完了画面からタイマーを再開する際に、アニメーションが正しく動作するようになりました
- **ロック画面表示の改善**: Live Activityでタイマー終了後の表示が正しく更新されるようになりました

これらの修正により、より安定したタイマー体験を提供できるようになりました。

## 🇺🇸 English Version

### What's New in This Version

**Bug Fixes and Stability Improvements**

This update includes the following fixes:

- **Timer Display Fix**: Fixed an issue where the timer would not display the correct initial value when restarting after session completion
- **Animation Fix**: Fixed an issue where animations would not trigger when restarting the timer from the completion screen
- **Lock Screen Display Fix**: Fixed Live Activity display update issue after timer expiration

These improvements provide a more stable and reliable timer experience.

---

## 📝 変更内容の詳細（開発者向け）

### 修正された問題

1. **タイマー初期表示問題**
   - Quiet Cosmos状態からの再スタート時に、初期値が一瞬で1秒減る問題を修正
   - 秒境界のアラインと単調時計ベースの表示ゲートを実装

2. **アニメーション不発火問題**
   - セッション完了後のリセット時に購読が失われる問題を修正
   - `reestablishBindings()`で全購読を再確立

3. **Live Activityカウントアップ問題**
   - タイマー終了後の背景カウントアップを防止
   - `Text(timerInterval:countsDown:)`を使用して正確な表示を実現

### 技術的な改善

- タイマーエンジンの精度向上（秒境界アライン、単調時計ゲート）
- 購読管理の一元化とコードの重複削減
- ドキュメントの追加（問題の原因分析と解決策）
