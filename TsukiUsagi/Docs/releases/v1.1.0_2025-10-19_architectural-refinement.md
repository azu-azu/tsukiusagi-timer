
## 📝 説明文（v1.1.0）

**TsukiUsagi Timer v1.1.0** は、アーキテクチャの改善とユーザー体験の向上を目的とした大規模アップデートです。
テキスト管理システムや日次振り返り機能を中心に、設計品質と操作性を高めました。

---

### 🌙 主なアップデート内容

**● テキスト管理の再設計**

* Labels / Copy / Messages の3層構造を採用し、テキストを体系的に管理
* コード品質と一貫性を自動でチェックする仕組みを導入

**● 日次振り返り機能の改善**

* 旧メモUIを廃止し、日次振り返りを統一
* 新しいフルサイズエディタ「LargeTextEditorSheet」を追加
* アイコン操作による展開・折りたたみで使いやすさを向上

**● タスク管理の整理**

* `subtitleLabel` を `taskLabel` に統一し、自動移行に対応
* サイドバーとの連携を改善

**● 編集アイコンとデザイン統一**

* 鉛筆アイコンの色と意味を統一
* タスク欄の文字色・空状態のデザインを最適化

**● 履歴・ナビゲーション改善**

* 履歴タイムラインを最新順にソート
* シート閉じるボタンやリセットボタンの配置を見直し
* 誤タップ防止・操作性を向上

**● コードと国際化の改善**

* SwiftLint違反や重複キーを整理
* Copy.swift構造を最適化し、翻訳管理を簡潔化

**● 不具合修正**

* 「静かな月」状態でリセットタイマーが動作しない問題を修正

---

🌕 **今回のアップデートは、“詩的で静かな体験”を保ちながら、より安定した使いやすさを目指した改善版です。**

**（英語版 for bilingual submission）**

**TsukiUsagi Timer v1.1.0** is a major update focused on architectural refinement and smoother daily reflections.
It improves text management, consistency, and overall UX quality.

* Introduced 3-layer text classification (Labels / Copy / Messages)
* Unified daily reflection with full-size editor
* Improved sidebar and task label consistency
* Refined edit icons, layout, and accessibility
* Enhanced history sorting and navigation
* Fixed an issue where reset timer did not activate in “Quiet Moon” mode
