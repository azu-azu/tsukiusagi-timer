### [☑️] **25/5のデフォルト（作業25/休憩5）**
  **狙い**：初回起動から迷わず使える既定値を用意。
  **合格ライン**：初回インストール直後、作業25分・休憩5分が設定画面に表示＆即使用可能。
  **実装ヒント**：

  * `UserDefaults` にキー例：`workMinutes=25`, `breakMinutes=5`。
  * 初回起動時に未設定ならデフォルトを書き込む（アプリ起動ごとに上書きはしない）。

  • 実装は満たしています。確認結果:
    • @AppStorage で workMinutes = 25, breakMinutes = 5 が定義済み
    • 初期値として 25/5 がビュー/VMに適用される
    • シミュレータ環境では、未設定時に UserDefaults.standard に 25/5 を書き込み（初回のみ）するガードあり

  該当箇所:

   TsukiUsagi/Features/Timer/ViewModels/TimerViewModel.swift

     1 │ @AppStorage("workMinutes") private var workMinutes: Int = 25
     2 │ @AppStorage("breakMinutes") private var breakMinutes: Int = 5
     3 │
     4 │ #if targetEnvironment(simulator)
     5 │ if UserDefaults.standard.integer(forKey: "workMinutes") == 0 {
     6 │     UserDefaults.standard.set(25, forKey: "workMinutes")
     7 │ }
     8 │ if UserDefaults.standard.integer(forKey: "breakMinutes") == 0 {
     9 │     UserDefaults.standard.set(5, forKey: "breakMinutes")
    10 │ }
    11 │ #endif
    12 │
    13 │ self.timeRemaining = workMinutes * 60

  • 補足:
    • 端末実機では @AppStorage のデフォルト値がそのまま初期表示になります（上書きはしません）。必要なら同様の初回書き込みガードを実機にも適用可能です。

#### 実装チェック結果（ふじこ視点）

* `@AppStorage("workMinutes") = 25` / `@AppStorage("breakMinutes") = 5`
  → SwiftUI標準の初期値が定義されとるから、初回起動でもビュー/VMに 25/5 が適用される。

* シミュレータ用のガード処理 (`#if targetEnvironment(simulator)`)
  → `UserDefaults.standard.integer(...) == 0` の場合だけ、25/5 を書き込む仕組み。
  → これで「初回は必ず値が入る」ことを保証できてる。

* 実機ではガードなしでも @AppStorage 初期値がそのまま出る
  → その後ユーザーが変更したら、自動で `UserDefaults` に保存される。
  → 上書きしない＝ユーザー設定を尊重する挙動になってる。

* 実機でも「UserDefaults に確実に書き込んでおきたい」なら、シミュレータと同じガード処理を共通で書いてもOK。
  → ただ、@AppStorage の初期値で十分やから、必須ではない。
* この構造やったら **「初期値だけ設定 → その後はユーザー優先」** が保証されとるから安心やで。

### [☑️] **フォアグラウンドのカウントダウン（1秒精度）**
  **狙い**：画面を見てる間は“ちゃんと減ってる”体感を担保。
  **合格ライン**：1秒ごとにUI更新、ドリフト（ズレ）が目に見えない。
  **実装ヒント**：

  * 発火源は`Timer.publish(every: 1, ...)`よりも\*\*基準は常に「目標時刻 - 現在時刻」\*\*で差分計算。
  * カウントを+/-するのではなく、`endAt - now` を毎秒再計算してUI表示に反映（ドリフト防止）。

### [ ] **中断→再開（アプリ再起動時に残り時間を再構成）**
  **狙い**：アプリを閉じても“続きから”が自然に戻る。
  **合格ライン**：強制終了→再起動しても残り時間が正しく復元される（負になってたら0扱い）。
  **実装ヒント**：

  * スタート時に**絶対時刻**の`endAt`（`Date`）を`UserDefaults`に保存。
  * 起動時に`remaining = max(0, endAt - now)`で再計算。
  * 一時停止/再開を付けるなら、そのたびに`endAt`を再定義（現在時刻+残り）。

---

### [ ] **バックグラウンド時：終了時刻でローカル通知**
  **狙い**：画面を見てなくても終了を確実に知れる。
  **合格ライン**：ホームに戻ってもスリープしても、終了時刻に通知が来る。
  **実装ヒント**：

  * 開始時に`UNUserNotificationCenter`で`endAt`に合わせて通知を**1つだけ**スケジュール。
  * 設定変更/停止時は**既存通知をキャンセル→再スケジュール**。
  * 通知許可ダイアログは初回起動or初使用時に丁寧に。

---

### [ ] **設定画面：数値入力＋保存（UserDefaults）**
  **狙い**：ユーザーが自分の好みに即合わせられる。
  **合格ライン**：分数を変更→保存→次回起動でも反映。
  **実装ヒント**：

  * 分数は`Stepper`や`TextField`(数字専用)で。
  * 保存は`onChange`（iOS17以降の新シグネチャ）で即時反映、または“保存”ボタンで明示。
  * 妥当性チェック（例：最小1、最大180）。

### [ ] **クラッシュ0件で24時間動作確認**
  **狙い**：最低限の信頼性。
  **合格ライン**：連続24時間（スリープ・再起動・バックグラウンド遷移含む）でクラッシュなし、終了通知も正しく機能。
  **実装ヒント**：

  * 端末実機で、短時間・長時間・画面回転・省電力モード・言語/時間形式(12/24h)をざっと網羅。
  * クラッシュログ（Xcode Organizer / デバイスログ）とアプリ側簡易ログで確認。
