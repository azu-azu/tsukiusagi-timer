### 5. Architecture Adjustments / 構造上の変更

| Component                       | Change                         | Purpose                   |
| ------------------------------- | ------------------------------ | ------------------------- |
| `NotificationManager`           | Full refactor                  | Reduce global coupling    |
| `PhaseNotificationService`      | Scoped cancellation            | Prevent delayed residuals |
| `TimerViewModel+SessionControl` | Pause/resume unification       | Prevent state drift       |
| `TsukiUsagiApp.swift`           | Deep link + Live Activity init | Single source of truth    |
| `AppDelegate.swift`             | Notification setup merge       | Reduce duplication        |

---

### 6. Technical Decisions / 技術上の判断

| Topic                | Decision                      | Rationale                     |
| -------------------- | ----------------------------- | ----------------------------- |
| Activity lifecycle   | Instance-based manager        | Avoid static state leaks      |
| OS version           | `#available(iOS 16.1, *)`     | Ensure backward compatibility |
| Multi-session policy | Single activity enforced      | Prevent UI race conditions    |
| Update frequency     | 1–5s, no 1s tick              | Battery & CPU optimization    |
| Logging              | `os.Logger` structured format | Telemetry-ready logging       |
